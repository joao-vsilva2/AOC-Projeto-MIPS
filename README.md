# AOC Projeto MIPS
Desenvolvimento em Python de um simulador do microprocessador MIPS, implementado de forma incremental em três etapas.

## Funcionalidade do programa:
1. Digite o código MIPS em hexadecimal no "entrada.json" em "text".
2. E execute no terminal: ``python3 main.py entrada.json saida.json`` ou ``python main.py entrada.json saida.json``

O programa implementa as seguintes operações lógicas e aritméticas: ``add, sub, slt, and, or, xor, nor, mfhi, mflo, addu, subu, mult, multu, div, divu, sll, srl, sra, sllv, srlv, srav, addi, slti, andi, ori, xori, addiu``
